# 周杰伦经典专辑网站

介绍周杰伦 1999-2005 年发行的六张个人专辑，现代简约风格静态网站。

## 功能特点

- **首页**：周杰伦简介、音乐历程、六张专辑展示、时光轴
- **专辑详情页**：每张专辑的完整曲目列表
- **叶惠美专辑**：支持在线音频播放（11首歌曲）

## 部署到 GitHub Pages

1. 将代码推送到 GitHub 仓库
2. 进入仓库 **Settings** → **Pages**
3. 在 **Source** 中选择 **Deploy from a branch**
4. 选择 **main** 分支，根目录 **/ (root)**
5. 保存后等待部署完成

访问地址：`https://<你的用户名>.github.io/ArvinBlog/`

## 本地预览

```bash
# 使用 Python 启动本地服务器
python3 -m http.server 8000
# 访问 http://localhost:8000
```

或直接双击 `index.html` 在浏览器中打开。
